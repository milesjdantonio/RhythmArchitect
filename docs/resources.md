# Rythm Architect resources and tooling

What Claude Code (or a teammate) can use on this project, its status, and when to use it. Format and
rules follow TerraSim's docs/resources.md. Last checked 2026-10-31.

## Ground rules

- None of the design or review tools are runtime dependencies. The app runs with all of them missing.
- Ask before paid plans, credentials or API keys, system-wide installs, or downloading browsers or
  binaries. Tests and recordings use the Chromium and ffmpeg already in the Playwright cache.
- Test browsers: one at a time, with a time limit, always closed. Use `tools/browser.mjs`.
- Every Rive animation has a non-Rive fallback. Every 3D view has a 2D or static fallback.
- After any gameplay change (stage, effects, HUD, results, charts, mapper), re-record the gameplay
  video with `npm run video` and check a few frames.

## Project tools

| Tool | What it does |
|---|---|
| `tools/rive/build.mjs`, `check.mjs` | Writes `.riv` files from code; loads each in the real runtime and screenshots its states |
| `tools/map-audio.mjs` | Maps the bundled tracks with the onset mapper (decodes MP3 in a real browser) |
| `tools/record-video.mjs` | Records `docs/media/gameplay.webm` from Chrome's screencast and the cached ffmpeg |
| `tools/autoplay.mjs` | A bot plays a song and screenshots it (`--sloppy` for misses) |
| `tools/shot.mjs`, `flow.mjs` | Screenshots of the running app |
| `tools/browser.mjs` | The safe headless browser (lock file, time limit, always closed), from TerraSim |

## Skipped

| Resource | Why |
|---|---|
| Synthwave sun-and-grid backdrop | Too common; replaced by the cymatic sheet (the user's call). |
| Blueprint drafting on the backdrop (grid, rulers, dimension notes, title block) | Replaced 2026-10-31 by deep space, in the direction of Tetris Effect (the user's call); the cymatic sand stayed. |
| Hit sounds | Removed 2026-10-31: every tile is a note of the song, so the song is the sound (the user's call). |
| Album art in the mock | The mock has no art source; the contract has `cover` for the real backend, and covers fall back to cover.riv. |
| Postprocessing bloom on the stage | Breaks the transparent canvas; glow comes from additive sprites instead. |
